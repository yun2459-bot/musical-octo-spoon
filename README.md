# 🦺 AI 기반 현장 안전 데이터 통합 분석 대시보드 (프로토타입)

세방(주) 현장 안전 데이터를 통합 분석해 **지사별 위험지수**를 산출하고,
**점검 편향(사각지대)**을 자각시키며, 경보 지사에 **맞춤형 TBM 대본**을 자동 생성하는 시스템.

## 실행

```bash
pip install streamlit pandas numpy matplotlib plotly wordcloud
python clean_data.py          # 원본 → data/*.csv 정제 (최초 1회)
streamlit run app.py          # 대시보드 실행
```

## 구성

| 파일 | 역할 |
|---|---|
| `clean_data.py` | 원본 3파일 → 통합 정제 (위험분류 통일, 산재/재물 분리, 지사 매핑, 중복제거) |
| `scoring.py` | 위험지수·경보·편향·사각지대·갭·TBM 로직 (단독 실행 시 콘솔 리포트) |
| `app.py` | Streamlit 대시보드 (4개 탭) |
| `data/점검_clean.csv` | 점검 785건 (정제본) |
| `data/사고_clean.csv` | 사고 2,058건 (정제본, 인적재해 425건) |

## 설계 원칙 (핵심 결정 반영)

- **위험지수**는 *점검 심각도* 기반으로만 산출 (0~100 정규화).
- **과거 산재이력**은 점수에 곱하지 않고, *경보 임계값을 낮추는* 조정 요소로만 사용 → 재발 민감도↑, 편향 고착 방지.
- **재물·차량사고(73%)는 위험지수에서 제외**, 인적재해(상해+산재)만 이력 가중치 대상.
- **물량 축은 이번 단계 제외** (물류 데이터가 익명·2024년만 존재).
- 심각도: 개선필요[하/중/상]=1/2/3, 규정위반=4.

## 대시보드 탭

1. **전사 상황판** — 🧭 위험지수 해석 가이드 · 지사별 위험지수 **(총량 / 사업장당 / 안전관리자당 정규화 전환)** · **점검 '양 vs 질' 산점도** · 규모·지수 표 · 히트맵 · 월별 추이 · 경보 목록
2. **지사 상세** — 위험지수 게이지 · 동적 워드클라우드 **2종(코칭내용 / 조치내용 분리)** · 자동 TBM 대본 · 과거재해 이력
3. **점검 편향분석** — 점검자별 다양성지수(**막대 클릭 시 위험분류·사업장 드릴다운**) · 전사/지사별 갭분석 · 점검 사각지대 · **전사/지사별 자동 인사이트**. 질병성(근골격) 재해는 편향분석에서 제외.
4. **조치활동** — 통제위계 분포(건수 많은 순) · 위험분류별 조치 구성

### 위험지수 정규화 (지사 규모 보정)
지사마다 **안전관리자 수·사업장 수**가 달라 총량 비교는 불공정할 수 있음. `branch_risk_index()`가 세 지표를 함께 산출:
- **총량지수**: 심각도 가중합(원지표)
- **사업장당지수**: ÷ 사업장수 (예: 당진 총량 84 → 사업장당 100, 1개 사업장 집중)
- **관리자당지수**: ÷ 안전관리자수 (예: 경북 총량 44 → 관리자당 88, 1명이 9개 사업장 담당)
사업장 = `Area/공정`에서 `지사_` 뒤 부분으로 추출.

> **위험지수 해석**: 높음 = 위험이 큼(집중관리 필요), 낮음 = 안정. 지사 평가·처벌 점수가 아니라 본사의 자원배분 우선순위 지표. 점검을 많이 해 지수가 오르는 것은 위험을 잘 발굴한 것이므로, '양 vs 질' 산점도로 건수와 심각도를 분리해 해석함.

## 주요 발견 (실데이터)

- 최고 위험지수: **강원지사 100점** (부산 85, 당진 84 순). 단 강원은 '건수'가 많고 부산은 '평균 심각도'가 높음 → 양/질 구분 필요.
- **무리한동작(근골격)**: 사고비중 14%이나 점검 0% — **그러나 질병성(지연발현) 재해**라 현장점검으로 포착이 어려움 → 사각지대가 아니라 **별도관리(근골격계 유해요인조사·인간공학 개선)** 대상.
- **화재·폭발**: 인적재해엔 거의 없지만 사고자료 전체에 **59건** → 활발한 점검은 **정당**(과다점검 아님).
- **풍수해**: 사고자료 **73건**인데 점검 항목 부재 → **우기/동절기 사전점검 체크리스트 신설 필요**.
- 임계값 조정 작동: 광양지사 끼임·협착(과거재해 12건) 등 저강도에도 경보.

> **사고 데이터 해석 주의**: 인적재해(상해+산재, 425건)만 보면 화재·풍수해가 0으로 보이지만, 재물·기타 사고까지 스캔하면 실제로 다수 존재. 갭분석은 `safety_accident_hazard()`로 인적재해 + 화재·폭발 + 풍수해를 합산해 비교한다.
